# PicGrabber

Material sichten, Stellen markieren und Bilder aus dem Video ziehen –
läuft lokal auf dem Mac, ohne Upload.

**→ [Herunterladen und loslegen](https://klassenmedia.github.io/picgrabber-download/)**

## Was es kann

- Videos aus einem Ordner durchsehen, frameweise navigieren
- Einzelbilder in voller Qualität speichern, Zielordner frei wählbar
- Szenen mit In-/Out-Punkten markieren, bewerten und kommentieren
- Am Ende eine kleine Review-Datei exportieren

Die Videos bleiben auf dem eigenen Rechner. Zurückgeschickt wird nur eine
Textdatei mit den Markierungen.

## Installation

Herunterladen, entpacken, Doppelklick auf `PicGrabber_STARTEN.command`.
Beim ersten Start wird einmalig Python installiert – sonst nichts.
